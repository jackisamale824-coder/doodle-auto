# Verification record

Evidence is generated by `npm test`, `npm run build`, and `node scripts/browser-check.mjs`.

## Reference inspection

Inspected the live reference's publicly served HTML, styles, movement, renderer and NPC modules. Captured `output/playwright/reference-menu.png` and `reference-game.png` with Chromium. The reference uses Three.js 0.170, a screen-space paper/ink renderer, and PeerJS networking. No confirmed public repository was found.

1. Built and captured the original menu and first-person street scene.

3. Corrected shader output color space and reduced hatch density; reduced and repositioned the weapon; added subtle notebook ruling and a HUD readability backdrop.
4. The source test records subsequent menu, street, vault, grapple, interior, rooftop, combat and multiplayer screenshots.

## Gameplay verification boundaries

- Unit/integration tests run the actual Rapier controller; they do not replace collision with mocks.
- The staircase test walks every building in a generated 25-building city from entrance to roof.
- WebSocket tests use actual sockets and the real room manager. Controlled player locations isolate hit/occlusion scenarios.
- Browser checks drive real keys and mouse buttons. Position/aim fixtures make traversal scenarios reproducible. The full stair route executes physical movement, not position teleportation between steps.
- Death and progression checks explicitly use fixtures for lethal damage and completed objectives. They verify the lifecycle transitions rather than claiming a full manually completed campaign.
- Multiplayer is checked using two independent browser contexts on one local server. External hosting, Internet latency and cross-network play require a separate deployment test.

Fresh run results and screenshot names are in `output/playwright/browser-results.json`.

The final service on port 4173 was checked again with the same production browser tests.

The initial physics chunk contains Rapier's embedded WebAssembly (~835 KB gzip), so Vite reports a large-chunk advisory; this is not a build failure. Rapier also emits an upstream initialization deprecation warning with its documented no-argument initializer.
- Multiplayer crouch height and weapon origins are also replicated and regression-tested.
- Headless software-rendered multiplayer ran at roughly 21 fps on this host. No hardware-GPU performance claim is made.

The visual loop also improved stair headroom and stairwell sides, lowered risers to 18 cm, fixed Escape closing the newly opened pause dialog, reset stale input latches, and added collision hulls for rendered rooftop tanks and parked cars.
